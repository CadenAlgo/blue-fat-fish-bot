# 蓝色大肥鱼 · Blue Fat Fish

> 一个住在 QQ 里的拟人助手。DeepSeek 的拟人形象，蓝头发、鲸鱼尾巴，
> 会聊天、查天气、查快递、上网搜、看图、下视频、记提醒。

自己电脑上跑，数据全在本机，不依赖任何云服务（除了你选的大模型 API）。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 聊天 | 人设写在 `persona.md`，改完保存立刻生效 |
| 看天气 | Open-Meteo，免费无 key，重名城市会按省份和人口消歧 |
| 查快递 | 快递100，免 key 可用；填了自己的 key 就走官方接口 |
| 上网搜 | DeepSeek 官方 Search 接口；换别家模型时退回 Bing |
| 读网页 | DeepSeek 官方 Fetch 接口，返回正文 |
| 看图 | 图片下载到内存、转 base64 送模型，不落盘 |
| 下视频 | 发 B 站/抖音/快手/小红书链接，自动下 1080P 发回来，然后删本地文件 |
| 定时提醒 | 一次 / 每天 / 每周 / 工作日，到点主动私聊 |
| 发表情包 | 从 `stickers/` 里按标签挑，有频率限制 |
| 发消息 / 发邮件 | 仅主人可用 |
| 防刷屏 | 短时间刷屏自动拉黑，并通知主人 |
| 控制台 | 本地网页，改人设、换模型、管表情包、看日志 |

## 快速开始（Windows）

1. 装 **Python 3.12+**（安装时勾选 *Add python.exe to PATH*）
2. 准备 **NapCat**（第三方 QQ 协议端，见下方「风险说明」）
   - 本项目默认读取 `../napcat/shell`，可在 `config.json` 里改
3. 双击 **`启动大肥鱼.bat`**
4. 第一次会装依赖，然后拉起 NapCat，扫码登录
5. 浏览器打开 `http://127.0.0.1:8765`，在「模型」里填 API Key，点「测试」
6. 去 QQ 里私聊她，或在群里 @ 她

之后日常启动只有一步：双击 `启动大肥鱼.bat`。
停服务：双击 `关闭大肥鱼.bat`。

## 配置

| 文件 | 放什么 | 会不会进仓库 |
|---|---|---|
| `.env` | 模型 API Key、接口地址 | **不会**（已 gitignore） |
| `config.json` | 行为配置：话量、群聊触发、防刷、表情频率 | **不会** |
| `persona.md` | 她的人设 | 会（只是角色设定） |
| `profile.md` | 主人档案 | **不会**（用 `profile.example.md` 复制） |
| `stickers/` | 表情包 | **不会** |

模型支持任何 OpenAI 兼容接口：DeepSeek、阶跃星辰、通义、智谱、Kimi、硅基流动、OpenAI、本地 Ollama……
面板里有预设，填好点「测试」会直接告诉你通没通。

## 控制台

`http://127.0.0.1:8765`

- **概览**：说话密度、群聊触发方式、防刷屏、临时文件
- **模型**：服务商预设、API Key、模型名、温度、配置档一键切换
- **人格**：人设、主人档案、快递 key、发邮件配置
- **表情包**：上传/删除/打标签，调发送频率
- **提醒**：所有待发提醒
- **对话**：最近聊天记录

## 风险说明（重要）

本项目通过 **NapCat / OneBot** 接入 QQ，这属于**第三方协议实现，不是腾讯官方接口**。

- 违反 QQ 用户协议，**有被风控、限制登录甚至封号的风险**
- 建议：用小号、固定一台设备、不要高频群发、不要和手机同时登同一个号
- 如果收到「外挂风险」提示，最稳妥的做法是停用，或者改用官方机器人平台
- 本项目**不提供任何绕过检测、绕过验证的手段**

想长期稳定，请走 **QQ 开放平台**（q.qq.com）的官方机器人，那是合规路线。

## 常见问题

**面板显示 QQ 离线**
NapCat 没连上。看 NapCat 窗口有没有登录成功；电脑版 QQ 如果开着并登着同一个号，NapCat 会登不上——完全退出 QQ（托盘退出，不是退出登录）再试。

**报「当前账号已登录，无法重复登录」**
同上，QQ 进程还占着账号。双击 `清理后台.bat` 选 2，再重启。

**群里不回**
默认只有被 @ 才回。控制台「概览」里改成「提到名字就回」或「每句都接」。

**回答太长 / 太短**
「概览」里拖「说话密度」，0 最省字，5 最话痨。

**搜索报错**
搜索走 DeepSeek 官方接口，换成别家模型时会自动退回 Bing，功能弱一些但能用。

**表情包发得太频繁**
「表情包」页拖低发送频率，或调长冷却时间。
