# 蓝色大肥鱼 · QQ 机器人

一个住在 QQ 里的 AI 助手：会聊天、会查天气、会上网搜、会读网页、会看图。
人设、"话痨程度"、模型都能在本地网页控制台里调。

## 快速开始

1. 装 Python 3.12 以上（安装时勾选 **Add python.exe to PATH**）
2. 双击 **`启动大肥鱼.bat`**
3. 第一次会自动装依赖，然后拉起 NapCat（QQ）
4. 如果弹出二维码，用**手机 QQ 小号**扫码确认
5. 浏览器会自动打开控制台 `http://127.0.0.1:8765`，在里面填 API Key
6. 去 QQ 里私聊它，或者在群里 **@它**

之后的日常启动就一步：双击 `启动大肥鱼.bat`。账号登录态会记住，不用反复扫码。

## 怎么关掉

双击 **`关闭大肥鱼.bat`**，等三四秒，两个黑窗口会自己关掉。

也可以直接关掉那两个黑窗口：一个是主程序，一个是 NapCat（QQ）。两个都关才算全停。

> 只关主程序、留着 NapCat 的话，QQ 还挂在线上但没人回消息；下次启动会直接接上它。

## 它会什么

| 能力 | 说明 |
|---|---|
| 聊天 | 人设写在 `persona.md`，改完保存立刻生效 |
| 查天气 | Open-Meteo，免费无需 key；重名城市会按人口和省份消歧 |
| 上网搜 | DeepSeek 官方 Search 接口（`/v1/tools/search`） |
| 读网页 | DeepSeek 官方 Fetch 接口（`/v1/tools/fetch`），返回正文 |
| 查快递 | 快递100 公共查询接口，免 key；会自动猜快递公司 |
| 定时提醒 | "明早七点叫我"，到点主动私聊；支持每天重复 |
| 看图 | 图片会下载后直接送进模型，能描述、能认图 |
| 多轮记忆 | 每个群/私聊独立记最近 12 轮 |

## 控制台

`http://127.0.0.1:8765`

- **说话密度** 0~5：0 是"哑巴鱼"（一句话），5 是"话痨"（爱追问、爱插嘴）
- **群聊触发**：只有 @ 才回 / 提到名字就回 / 每句都接
- **模型**：接口地址 + API Key + 模型名，任何 OpenAI 兼容接口都能填；点"拉取"能看到可用模型
- **人设**：直接编辑 `persona.md`
- **重启 NapCat**：换号、掉线、二维码过期时点这个

## 开源前要做的

已经准备好：

- `.gitignore` 忽略了 `.env`、`config.json`、`data/`
- `.env.example` 和 `config.example.json` 是模板，只有占位符

交出去之前确认这三样没有被提交：`.env`、`config.json`、`data/`。

## 防刷屏

默认规则：**同一个人 60 秒内超过 20 条 → 拉黑 1 小时**。

- 触发时给对方回一句"你刷太密了"，然后一小时不理他
- 同时给你的大号发一条私聊：是谁、在哪个群/私聊、最后说了什么
- 黑名单存在 `data/blacklist.json`，重启不丢
- 面板「防刷屏」卡片能改阈值、改接收报警的 QQ、查看和手动解封
- `admin_qq` 填的那个号永远不受限（你自己刷不会把自己关进去）

## 查快递

直接把单号发过去就行：

```
773123456789012 到哪了
```

它会按单号前缀猜快递公司，猜不中会问你是哪家。结果缓存 5 分钟，不会反复打接口。

> 用的是快递100 的公共查询接口，免 key。量大了可能被限流，到时候可以换成你自己的 key。

## 定时提醒

```
明早七点提醒我跑步
每天八点提醒我吃药
每周一早上九点提醒我交作业
工作日晚上十点提醒我泡脚
我定了哪些提醒？
```

到点它会主动私聊（在群里定的就发群里）。提醒存在 `data/reminders.json`，重启不丢。
支持一次、每天、每周、工作日四种重复。控制台能看到所有待发提醒，也能手动删。

## 视频下载

把 B 站、抖音、快手、小红书、微博（以及 YouTube、X）的链接发过去，它会：

1. 回一句"本鱼去下"
2. 用 yt-dlp 下最高画质（优先 1080P H.264，手机能播）
3. 把文件直接发回 QQ
4. 三分钟后删掉本地文件

国内站点**强制直连**（走代理会被 B 站当境外 IP 拦），国外站点走代理。

需要更高画质（B 站高码率/4K）或抖音要登录态时，在 `config.json` 里填：

```json
"video": { "cookies_file": "cookies.txt" }
```

`cookies.txt` 放进项目根目录即可（浏览器插件导出）。也可以填 `"cookies_browser": "edge"`，
但那要求浏览器先关掉。

## 主人档案

`profile.md` 是"你是谁"，会拼进系统提示词，所以它认得你的名字、称呼和关系人。
控制台有对应的编辑框，改完保存，下一条消息生效。

> 只放它聊天时用得上的事。学校经历、项目清单这些它用不上，塞进去只是白花 token。

## 关于缓存

DeepSeek 的上下文有自动缓存：**前缀越稳定，命中越多，越省钱**。

所以提示词顺序是故意的：人设 → 档案 → 规则 → 场景 → 时间。时间每分钟都变，放最后；
前面那一大段每轮一致，就能整段命中缓存。

## 主动发消息 / 发邮件（只有主人能用）

```
给小号 12345678 发一句：我下课了
发邮件给 abc@qq.com，标题写「作业」，正文是……
```

- QQ 消息走 NapCat 的私聊接口，**对方必须是机器人的好友**，否则发不出去
- 邮件走 SMTP，面板里填发件邮箱和**授权码**（不是登录密码），勾上「开启邮件功能」
- 别人让它发，它会直接拒绝；主人用的时候它会先复述一遍收件人和内容

## 模型配置档

面板里可以把「地址 + key + 模型 + 温度」存成一套，起个名字。
以后在列表里点「切换」就换过去了，不用重新填。密钥存在 `data/profiles.json`，不进仓库。

## 表情包

面板「表情包库」可以上传、打标签、删除；也可以直接把图丢进 `stickers/`。
文件名就是标签，建议写成 `开心_01.png` 这种，她按标签挑图。

- **发送频率**：面板上拖滑杆，默认 35%，越低越「稀有」
- **冷却**：两条之间至少隔多少秒，默认 120 秒
- 会尽量不连着发同一张

## 发邮件

面板填**发件邮箱**（任何支持 SMTP 的邮箱，QQ 邮箱要授权码），然后对它说：

```
发邮件给 abc@qq.com，标题「周报」，正文「这周的事……」
```

> 授权码忘了不要紧，QQ 邮箱设置里可以重新生成，旧的作废、新的覆盖即可。
> 目前只支持纯文本正文，附件以后再说。

## 常见问题

**二维码过期 / 想换号**
控制台点"重启 NapCat"，或者关掉 NapCat 窗口再双击启动，用新号扫码。

**群里不回我**
默认只有 @ 才回。控制台把"群聊触发方式"改成"提到名字就回"或"每句都接"。

**回答太长 / 太短**
拖"说话密度"。数字越小越省字。

**搜索报错**
搜索和抓取走 DeepSeek 官方接口，按次计费 5 元 / 1000 次（2026-11-01 之前免费）。
余额不足时会自动退回 Bing 抓取。
